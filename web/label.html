Severity measures impact, not tone or stars

  • 1 No reported problem: praise, neutral/unclear text, or a pure feature request.
  • 2 Dislike, generic criticism, or annoyance; no supported functional loss.
  • 3 Degraded or restricted function; some use or a workaround remains.
  • 4 A core task is clearly blocked, such as login or playback.
  • 5 Explicit serious financial, privacy, or data harm.

Cancellation, anger, or an expensive plan alone does not establish high severity. Flag missing context for review; do not invent impact.

Topic and intent rules
  • access：Login, signup, password, account access
  • usability：Controls, layout, queue, playlist management, ads
  • playback：Playback failure, crashes, lag, connection, audio quality, resource use
  • downloads：Downloads, offline listening, disappearing downloads
  • catalog：Content, search, recommendations, lyrics
  • billing：Price, charges, paywalls, premium entitlement, explicitly premium-only controls
  • support：Support contact and response
  • other：General evaluation, unrelated text, no supported specific topic

Choose the highest supported severity; ties use the first specific problem. For praise, use the first specific feature. A paying user experiencing a crash is still playback.

Intent precedence: explicit leaving/uninstalling/cancelling/threat → complaint (including mixed) → request without failure → praise → unclear. Bare boycott slogans are usually unclear.
